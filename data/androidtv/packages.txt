# Android TV / Google TV packages to disable. Unlike the Fire OS list these are
# `pm disable-user`d, not uninstalled: they live in /system on every build seen
# so far, so uninstalling is not on offer and disabling is fully reversible.
#
# Verified on real hardware. Do not copy a list from another TV, and do not
# uncomment a line you have not watched survive a reboot on your own device.
# Build candidates with ./scripts/discover.sh — but note its name heuristic
# finds nothing on Google TV (Google's telemetry is not called "analytics"),
# so this list was assembled by reading `pm list packages` by hand.

# --- ads, attribution and on-device personalisation ---
com.android.adservices.api                   # Privacy Sandbox ad APIs (topics, attribution)
com.android.ondevicepersonalization.services # on-device ad personalisation
com.android.federatedcompute.services        # federated learning for personalisation

# --- telemetry, feedback and crash reporting ---
com.google.android.feedback                  # crash/feedback upload
com.android.tv.feedbackconsent               # TV feedback consent collector
com.google.android.partnersetup              # OEM partner referrer / attribution setup

# --- promo surfaces ---
com.google.android.apps.tv.dreamx            # Google TV ambient screensaver: serves promo art

# --- vendor nag (harmless elsewhere: debloat.sh skips absent packages) ---
com.onn.updatenotification                   # onn/Walmart update nagger

# --- unused features, not telemetry -------------------------------------
# Verified safe on onn Streaming Device 4K Pro (Android 14), but they are dead
# weight rather than tracking, so they stay commented: the file's remit is ads
# and telemetry. Uncomment per household if you want the disk/RAM back.
# com.android.cts.ctsshim                    # CTS test stub, no runtime purpose
# com.android.cts.priv.ctsshim               # CTS test stub, no runtime purpose
# com.android.printspooler                   # printing from a TV
# com.android.healthconnect.controller       # Health Connect on a TV
# com.android.health.connect.backuprestore   # Health Connect on a TV

# --- feature removals: ASK FIRST, never unconditional --------------------
# These work, but each one costs the household something. configure.sh should
# ask before any of them; never enable them by default.
# com.google.android.katniss                 # Assistant + voice search. Stops hotword
#                                            # mic capture, but kills the remote's mic
#                                            # button and voice search with it.
# com.netflix.ninja                          # preinstalled Netflix. Remove only if the
# com.netflix.tokenmanager                   # household does not watch it; also kills
#                                            # the remote's Netflix hotkey.
#
# NOT in this list on purpose:
#   com.google.android.apps.tv.launcherx     # the home screen. Disabled by hand only as
#   com.google.android.tungsten.setupwraith  # part of a launcher swap (docs/OTHER-TVS.md),
#                                            # never as debloat. Both are on
#                                            # never-disable.txt for that reason.
#
# For single builds' documented choices and feature tradeoffs (not executable
# removal lists), see docs/devices/tcl-g08.md and docs/devices/tcl-g10.md.
